StudyLock

Setup — three steps

Do this once. After that, opening StudyLock and pressing start is the whole ritual.

1. Install the browser shield

This is what puts the overlay over distracting pages. Do it in both Chrome and Edge if you use both.

  1. Open chrome://extensions (or edge://extensions).
  2. Turn on Developer mode, top right.
  3. Click Load unpacked and choose the extension folder inside your StudyLock folder.
  4. Click Details on “StudyLock Shield” and switch on Allow in Incognito / InPrivate.

Pin it if you like — the toolbar icon shows the time left. It has no off switch.

2. Set your IGCSE Discord server

  1. In Discord: Settings → Advanced → Developer Mode, on.
  2. Right-click your IGCSE server’s icon → Copy Server ID.
  3. In StudyLock, click settings and paste it in.

During a session the Discord app is closed on sight. Discord in the browser stays open, but only at discord.com/channels/<your IGCSE server> — DMs, other servers, friends and discovery all get the overlay.

Leave the field empty and Discord is blocked completely instead.

3. Harden it (recommended)

Right-click harden.ps1 → Run with PowerShell, and accept the admin prompt. This one-time step:

  • runs the blocker as an elevated scheduled task that restarts at every logon and re-checks once a minute — so killing it in Task Manager buys you 60 seconds at most;
  • lets it blackhole distracting domains in the hosts file during a session, which covers Firefox, any other browser and any profile — not just the ones with the extension;
  • turns off Incognito, InPrivate, guest mode and new profiles, which would otherwise run without the extension.

Without this step everything still works — the blocker just runs unelevated, and a fresh browser profile without the extension would slip through.

What always stays open

These are on a hard allowlist that wins over every block rule — they can’t be overlaid, can’t be killed, and never reach the hosts file, even if something else on the lists would have matched them.

AppsClaude, Microsoft Teams, Notepad, the Clock/Timer app

To add to it, edit allowed_domains or allowed_processes in config.json between sessions. There is deliberately no in-app editor for the allowlist: adding an exception should take more effort than clicking a button while you’re bored mid-session.

Removing the extension doesn’t work. Chrome lets you delete any developer-mode extension, so the shield reports in to the blocker every few seconds instead. If Chrome or Edge is running during a session and its shield has been silent for 90 seconds, the blocker closes that browser — and closes it again a few seconds after each relaunch. Deleting or disabling the extension doesn’t unlock the browser, it costs you the browser for the rest of the session.

Because of this, install the extension in both Chrome and Edge. Edge ships with Windows, so an unshielded Edge would be a free pass — which means the blocker treats it as one and won’t let it stay open without the extension.

How it refuses to let you out

  • Removing or disabling the browser extension closes the browser, repeatedly, until it’s back.
  • No stop, pause or cancel exists anywhere in the app.
  • Closing the timer window does nothing — the blocker is a separate process.
  • Two blocker processes watch each other and restart the one that dies.
  • Rebooting doesn’t help: the session is stored on disk and resumes at logon.
  • Winding the system clock forward doesn’t help: the countdown also runs on a monotonic timer and takes whichever is longer.
  • Deleting state.json doesn’t help: the running blocker writes it straight back.
  • Killing the blocker doesn’t unblock the browser: the extension keeps the shield up for the rest of the session and only lifts it when the blocker itself says the time is up.
  • Editing config.json mid-session doesn’t help: the rules are frozen into the session at the moment you press start.
The honest limit. This is a user-level program on your own PC, not a corporate lockdown. Someone with administrator rights, enough patience and a boot into Safe Mode can always dismantle it — that is true of Cold Turkey and Freedom too. What it does guarantee is that quitting takes real, deliberate, inconvenient effort, which is the whole point. Don’t go looking for the seams.

Uninstalling the hardening: run unharden.ps1 as administrator. It refuses to run while a session is in progress.
